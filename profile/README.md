## The utility in five lines

- It does one job: keeping the contents of two chosen folders in agreement.
- It reaches beyond the internal disk, supporting synchronization across mounted network drives.
- It can run as a simulation first, producing a log of intended actions rather than performing them.
- It is a paid utility at nine US dollars, currently at release 2.5.9.
- It is built with Xojo, and the author maintains additional builds for other hardware and older systems.

## Every capability and what it actually does

| Capability | What happens in practice |
|---|---|
| Folder pairing | You nominate a source folder and a destination folder; everything the utility does is defined by that pair |
| Network drive support | A mounted network volume can stand on either side of the pair, so a Mac and a NAS share can be kept aligned |
| Simulation run | The pass executes as a rehearsal and reports what it would have done, leaving both folders untouched |
| Log output | The simulation's findings arrive as a readable log, which is the review step before committing |
| Narrow scope | No mail rules, no versioning system, no cloud account — the surface area is small enough to learn in one sitting |
| Xojo foundation | The application is written in Xojo, which is how the same project spans several generations of Mac hardware |
| Alternate builds | An ARM version and older builds for previous systems are published on the author's own website |
| Licence | A single paid licence at 9.00 USD for the current release, with no subscription attached |

The simulation deserves the attention. Most mistakes in folder synchronization mac work are not software failures but human ones: the wrong folder was picked, or the destination held something nobody expected. Reading a log of intended actions before any file is copied turns that class of mistake into a two-minute correction rather than a restore from backup.

Equally, network volume support is what raises this above a copy command. Once a share is mounted in the Finder, it can serve as either end of the pair, which covers the common household and small-office arrangement of a working Mac and a storage box in the corner.

## Builds, licence and where older versions live

The current release is 2.5.9, listed under System Utilities at nine US dollars. Because the project is built with Xojo, the author has been able to keep several parallel builds alive: an ARM version, along with Cocoa, Carbon and PowerPC editions aimed at earlier systems. Those older packages are not on this page — the author's own website is where they are published, and anyone maintaining a genuinely old machine should start there rather than with the current download.

For everyone else, the current build is the one to take. Anyone who needs to download synctwofolders for mac use will find a compact application that asks for two paths, offers to rehearse the work, and then does it. That is the entire proposition, and for keeping a project directory aligned with a backup folders mac destination, it is usually enough. Large synchronization suites bring scheduling engines, cloud connectors and rule editors that most people never open; this one skips all of it and keeps the part that matters — knowing what is about to happen before it happens.
